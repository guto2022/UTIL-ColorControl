# 🎨 UTIL-ColorControl

> **Status:** ✔️ Concluído

## 📖 Sobre

Este projeto é uma ferramenta utilitária desenvolvida para manipular e converter valores de cores (ex: RGB para Hexadecimal, ou vice-versa). O objetivo foi praticar a lógica de processamento de dados e a criação de funções reutilizáveis para operações comuns com cores.

---

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** JavaScript
*   **Ambiente:** HTML, CSS (para interface básica, se houver)

---

## ✨ Principais Aprendizados

*   Implementação de algoritmos para conversão entre diferentes formatos de cores.
*   Validação de entrada de dados para garantir formatos de cores corretos.
*   Organização de código em funções modulares e reutilizáveis.
